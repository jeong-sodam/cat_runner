# Plan: Cat Runner 시각 개선 및 한국어 전환

## Goal

처음 게임을 시작할 때 일시정지 창이 보이지 않도록 고치고, 여섯 고양이·세 구역 배경을 동화책풍 래스터 에셋과 애니메이션으로 표현한다. 시작부터 결과·순위표까지 모든 사용자 노출 문구를 명확한 한국어로 통일하며, 에셋을 불러오지 못해도 기존 캔버스 그림으로 플레이할 수 있어야 한다.
