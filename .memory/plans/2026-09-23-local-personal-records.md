# Plan: Local Personal Records

## Goal

로컬 플레이 결과를 게임오버 즉시 브라우저 저장소에 누적하고, 결과 화면에서 `개인기록표`와 서버용 `순위표`를 분리한다. 개인기록표에는 점수순 최고 기록 5개와 항상 별도로 표시되는 방금 기록을 제공하며, 최고 기록 5개 밖의 방금 기록에도 전체 개인 순위를 계산해 보여준다.

현재 서버 순위표 API 흐름은 유지한다. 로컬 모드에서는 서버 순위표를 호출하지 않고 준비 중 안내만 표시한다.

## Scope

- 로컬 기록 전체 이력 저장 및 점수순 개인 순위 계산
- 기존 단일 최고 기록/상위 5개 저장 데이터의 안전한 마이그레이션
- `개인기록표` 전용 화면과 결과 화면 버튼 분리
- 결과 화면의 잘못된 `순위표 미등록` 문구 제거 및 저장 결과/개인 순위 표시
- 기존 서버 `순위표` 화면과 서버 API 호출 경로 보존

## Non-goals

- 서버 전체 순위 API 또는 로그인 기능 구현
- 로컬 기록 삭제/초기화 기능
- 다른 브라우저·기기 간 로컬 기록 동기화
