# Decisions: 난이도·장애물 밀도·고양이 점프 연출

- Date: 2026-09-22
- Status: Confirmed

## D01. 현재 난이도 기준

- **Chosen**: 현재 계산식을 기준선으로 유지한다.
- **Rationale**: `calculateDifficulty(distanceM, zoneId)`는 거리 0~2000m에서 `1.0~1.5배`로 증가하고, zone 배수는 `home_day 1.0`, `outside 1.2`, `home_night 1.5`이다. 따라서 최대 이동 난이도는 각각 `1.5배`, `1.8배`, `2.25배`이며, zone 전환 점수는 `1000/2500`이다.

## D02. 장애물 밀도 단계

- **Chosen**: `home_day`는 기존 밀도를 유지하고, `outside`부터 기존 패턴을 `2/2/3` 장애물 수준으로 늘린다.
- **Rationale**: 초반 진입 장벽은 유지하면서 zone 전환 이후에 체감 난이도를 올린다. 현재 기본 패턴 장애물 수는 `1/1/2`이다.

## D03. 복합 패턴 해금

- **Chosen**: `home_day`에서는 기존 3개 패턴만 사용하고, `outside`부터 복합 패턴을 추가하며 `home_night`에서 전체 패턴을 사용한다.
- **Rationale**: zone 진행과 장애물 학습 곡선을 맞춘다.

## D04. 복합 장애물 패턴 구성

- **Chosen**: `PATTERN_LIBRARY`에 복합 패턴 6개를 명시적으로 추가하고, 시드 기반 선택으로 결정론적으로 섞는다. 점프·슬라이드 요구 순서는 패턴마다 다양화하며 기존 box·fence·pot·yarn을 균형 있게 사용한다.
- **Rationale**: 클라이언트와 서버가 같은 seed로 동일한 장애물·이벤트 흐름을 재현할 수 있고, 새 이미지 에셋을 늘리지 않는다.

## D05. 복합 패턴 반응 간격

- **Chosen**: 복합 패턴 내부 장애물 간 간격은 `100~140px`로 설정한다.
- **Rationale**: 점프와 슬라이드를 연속으로 요구하는 빠른 반응 구간으로 만든다. 기존 gap 안전 여유와 충돌하지 않도록 구멍 구간은 별도 안전 anchor로 유지한다.

## D06. 고양이 점프 애니메이션

- **Chosen**: 새 PNG를 추가하지 않고 기존 점프 프레임을 사용한다. `player.vy`가 음수일 때 상승, 양수일 때 하강으로 판단해 위치를 살짝 보정하고, 벡터 폴백에서는 다리 모양도 단계적으로 바꾼다.
- **Rationale**: 구현 비용을 낮추면서 현재 PNG·벡터 렌더링 양쪽에서 점프 움직임을 명확하게 보여준다.

## D07. 기존 게임 계약 보존

- **Chosen**: 장애물 피해량, 수집 점수·아이템 종류, 낙사 규칙은 유지한다. 새 패턴과 난이도 데이터는 클라이언트·서버 매니페스트에 함께 반영하고 버전을 갱신한다.
- **Rationale**: 이번 요청은 밀도·회피 패턴·연출 개선이며, 점수와 피해 밸런스까지 동시에 바꾸면 원인 분리가 어려워진다.
