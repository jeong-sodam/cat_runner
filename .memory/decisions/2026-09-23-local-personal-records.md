# Decisions: Local Personal Records

- Date: 2026-09-23
- Status: Confirmed

## D01. 기록표 역할 분리
- **Chosen**: `개인기록표`는 로컬 플레이 기록을 표시하고, `순위표`는 향후 서버 전체 순위를 위한 별도 기능으로 유지한다.
- **Rationale**: 현재는 서버 연결 없이 LOCAL 모드로만 플레이하므로 개인 기록과 서버 순위를 혼동하지 않도록 분리한다.

## D02. 결과 화면 버튼
- **Chosen**: 게임오버 결과 화면에 `개인기록표`와 `순위표` 버튼을 나란히 표시한다.
- **Rationale**: 플레이 직후 로컬 기록을 바로 확인할 수 있어야 하며, 향후 서버 순위 진입점도 미리 유지한다.

## D03. 서버 순위표의 로컬 상태
- **Chosen**: `순위표`는 현재 비활성 상태로 두고, 클릭하면 “서버 순위표는 준비 중입니다” 안내를 표시한다.
- **Rationale**: 로컬 기록을 서버 순위처럼 오인하게 만들지 않으면서 향후 기능의 자리와 흐름을 확보한다.

## D04. 개인기록표 표시 범위
- **Chosen**: 점수순 최고 기록 5개를 표시하고, `방금 기록`은 최고 기록 5개와 별도로 항상 표시한다.
- **Rationale**: 새 기록이 상위 5개에 포함되지 않아도 방금 플레이한 결과를 확인할 수 있어야 한다.

## D05. 개인 순위 계산
- **Chosen**: 모든 로컬 플레이 기록을 내부 저장하고, 화면에는 최고 기록 5개를 표시한다. 방금 기록이 5위 밖이어도 전체 개인 순위를 함께 표시한다.
- **Rationale**: 상위 5개 밖의 방금 기록에도 정확한 개인 순위를 제공하기 위해 전체 기록이 필요하다.

## D06. 순위 정렬과 동점 처리
- **Chosen**: 점수 내림차순으로 정렬하고, 동점이면 먼저 달성한 기록을 위에 표시한다. 순위는 고유하게 `1위, 2위` 형식으로 부여한다.
- **Rationale**: 표시 순서와 순위 번호가 일관되며 동점으로 인한 순위 건너뛰기를 피할 수 있다.

## D07. 기록 표시 필드
- **Chosen**: 각 기록에 순위, 점수, 거리, 정확도, 플레이 날짜·시간을 표시한다.
- **Rationale**: 점수뿐 아니라 플레이 성과와 기록 시점을 함께 비교할 수 있어야 한다.

## D08. 저장 시점과 유지 범위
- **Chosen**: 게임오버 즉시 자동 저장하고, 같은 브라우저의 새로고침·게임 재실행 후에도 로컬 저장소로 유지한다.
- **Rationale**: 수동 저장 누락을 방지하고 현재 서버 없는 플레이 환경에서도 기록을 지속적으로 관리한다.

## D09. 기록 초기화
- **Chosen**: 사용자 화면에는 기록 초기화 기능을 제공하지 않는다.
- **Rationale**: 이번 범위는 기록 저장과 조회이며, 실수로 기록을 삭제할 수 있는 조작은 추가하지 않는다.
