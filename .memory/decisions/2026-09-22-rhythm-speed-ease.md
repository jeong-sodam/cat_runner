# Decisions: Rhythm Speed Ease

- Date: 2026-09-22
- Status: Confirmed

## D01. Rhythm pacing

- **Chosen**: Slow rhythm target pacing by 1.5x across every zone.
- **Rationale**: The current osu-style targets feel too fast, so the timing window should become more approachable without removing the dual-input challenge.

## D02. Target lifetime

- **Chosen**: Increase target lifetime from 500ms to 750ms.
- **Rationale**: The player needs a larger reaction window in addition to the slower spawn cadence.

## D03. Bonus target pacing

- **Chosen**: Apply the same 1.5x pacing and lifetime adjustment to secondary-button bonus targets.
- **Rationale**: Both hands should follow the same readable rhythm rather than creating a hidden speed spike for bonus targets.

## D04. Zone target count

- **Chosen**: Keep the existing per-zone simultaneous target counts unchanged.
- **Rationale**: This adjusts timing difficulty while preserving the intended progression from home day to outside and home night.
