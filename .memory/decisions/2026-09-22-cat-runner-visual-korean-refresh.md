# Cat Runner 시각 개선 및 한국어 전환 — 결정 기록

## 목표

게임 시작 직후 일시정지 창이 사라지지 않는 문제를 해결하고, 고양이 러너의 전 화면을 따뜻한 동화책풍 2D 그래픽으로 개선한다. 게임 UI 전체를 한국어로 제공한다.

## 확정된 결정

- **일시정지 문제:** 화면이 처음 열릴 때 일시정지 오버레이가 보이지 않아야 하며, P 키 또는 일시정지 버튼으로 열었을 때만 표시한다. 현재 CSS의 `.pause-overlay { display: grid; }`가 `hidden` 속성의 기본 숨김 처리를 덮어쓸 수 있으므로, `[hidden]` 상태를 명시적으로 숨기는 방식으로 해결한다.
- **시각 스타일:** 부드러운 외곽선, 파스텔 계열 색감, 귀여운 고양이 표정의 따뜻한 동화책풍 2D 일러스트를 사용한다.
- **개선 범위:** 플레이 화면뿐 아니라 시작/로그인, 캐릭터 선택, 일시정지, 결과, 순위표, HUD까지 전 화면을 개선한다.
- **이미지 에셋:** 새 래스터 에셋을 추가한다. 여섯 고양이와 세 배경을 새 일러스트 에셋으로 만들며, 수집품과 장애물은 기존 코드 렌더링을 다듬어 사용한다.
- **고양이:** 검정·하양·삼색·치즈·고등어·카오스는 털색과 무늬뿐 아니라 꼬리 모양과 표정도 각기 다르게 만든다. 액세서리는 넣지 않는다.
- **고양이 애니메이션:** 달리기·점프·슬라이드에 대응하는 프레임 애니메이션을 제공한다.
- **배경:** 집 안 낮, 집 밖, 집 안 밤 배경을 길게 반복 가능한 형태로 만들고, 원경은 느리게 움직여 깊이감을 준다.
- **에셋 로딩:** 시작 화면에서 미리 로드한다. 에셋 로드에 실패하면 기존 캔버스 렌더링으로 안전하게 대체한다.
- **한국어 범위:** HUD를 포함한 게임의 모든 UI 문구를 한국어로 바꾼다. W/S/P 조작키 표기와 이메일은 그대로 유지한다.
- **한국어 문체:** 감정 표현보다 명확성을 우선하는 깔끔한 기본 UI 문체를 쓴다. 예: `재시작`, `점수`, `일시정지`.
- **레이아웃:** 게임 화면을 중심으로 구성하고, 메뉴와 결과창은 게임 배경 위에 작고 명확한 패널로 표시한다.
- **글꼴:** 외부 웹폰트 없이 시스템 한글 글꼴 우선순위를 사용해 첫 로딩과 오프라인 실행을 안정적으로 유지한다.

## 범위 밖

- 게임 규칙, 조작 방식(W 점프 / S 피하기 / P 일시정지), 점수와 아이템 설계는 이번 변경에서 바꾸지 않는다.
- 사운드, 신규 스테이지, 모바일 전용 조작 추가는 포함하지 않는다.

## 확인한 코드 기반 사항

- 현재 일시정지 컨트롤러는 `hidden` 속성으로 오버레이를 제어한다.
- 스타일의 `.pause-overlay { display: grid; }` 선언이 브라우저의 `[hidden] { display: none; }` 처리보다 우선할 수 있어 초기 노출 현상의 유력 원인이다.
- 렌더러는 고양이 및 아이템 스프라이트 대체 경로를 이미 지원하므로, 에셋 로더와 생성된 에셋을 연결하고 실패 시 기존 코드 렌더링으로 되돌릴 수 있다.
