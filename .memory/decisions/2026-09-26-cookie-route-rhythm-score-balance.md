# Decisions: 쿠키런식 쥐 루트·오수 속도·정확도 점수 보정

- Date: 2026-09-26
- Status: Confirmed

## D01. 일반 패턴의 쥐 인형 유도 루트
- **Chosen**: 모든 일반 패턴에서 장애물 회피 경로를 따라 쥐 인형을 배치한다.
- **Rationale**: 쥐 인형이 쿠키런처럼 다음 점프·슬라이드 행동을 안내해야 한다. 특수 5×5 진형은 기존 수집형 연출을 유지한다.

## D02. 루트의 안전성
- **Chosen**: 쥐 인형을 따라가면 해당 패턴의 장애물을 피할 수 있는 항상 안전한 루트로 만든다.
- **Rationale**: 쥐 인형은 시각적 장식이 아니라 실제 조작을 안내하는 경로여야 한다.

## D03. 루트 생성 기준
- **Chosen**: 패턴 스트림에서 확정된 실제 `requiredActions` 순서를 기준으로 만든다.
- **Rationale**: `jump`, `slide`, `double_jump`가 섞인 패턴에서도 화면의 쥐 루트와 실제 회피 동작을 일치시킨다.

## D04. 일반 쥐 인형 밀도
- **Chosen**: 기본 쥐 인형 1개당 최대 7개까지 안전 루트에 촘촘히 배치한다.
- **Rationale**: 기존 최대 3개보다 유도성이 강해지고, 장애물 사이 행동 변화가 시각적으로 이어진다.

## D05. 장애물 간격
- **Chosen**: 현재 패턴 간격 factor `0.6375`를 `0.733`으로 조정하고, 모든 패턴 내부 장애물 간격도 약 15% 늘린다.
- **Rationale**: 기본 `minGap 240` 기준 실제 외부 간격을 약 `176px`로 늘려 회피 여유를 확보한다.

## D06. 패턴 길이 확장
- **Chosen**: 내부 장애물 간격을 늘릴 때 패턴 `width`와 gap 위치도 함께 확장한다.
- **Rationale**: 장애물을 억지로 좁은 공간에 넣지 않고, 패턴의 안전 경로·간격·다음 패턴 위치를 함께 보존한다.

## D07. 오수 타겟 개수와 단계별 속도
- **Chosen**: 모든 단계에서 오수 타겟은 항상 1개로 유지한다. 1단계 `1000ms`, 2단계 `800ms`, 3단계 `600ms` 간격으로 생성한다.
- **Rationale**: 동시에 여러 개를 처리하는 부담 대신, 단계가 올라갈수록 한 타겟의 등장 템포만 빨라지게 한다.

## D08. 오수 타겟 수명
- **Chosen**: 각 단계의 생성 간격과 동일하게 타겟 수명을 설정한다.
- **Rationale**: 놓친 타겟이 오래 남아 다음 타겟을 막지 않도록 단계별 템포를 실제 플레이 흐름과 일치시킨다.

## D09. 오수 정확도 점수 보정
- **Chosen**: 정확도를 전체 달리기 점수에 선형으로 반영하며, 정확도 0%는 `0.5배`, 50%는 `1.0배`, 100%는 `1.5배`로 계산한다.
- **Rationale**: 현재보다 정확도 차이를 극단적으로 드러내어 오수 플레이 성과가 최종 점수에 분명히 반영되도록 한다.

## D10. 오수 미시도 처리와 결과 표시
- **Chosen**: 오수 시도 횟수가 0이면 정확도 보정 `0.5배`를 적용하고, 결과에 정확도·보정 배율·최종 점수의 관계를 표시한다.
- **Rationale**: 오수를 전혀 하지 않고 최고 정확도로 처리되는 문제를 막고, 점수 변화 원인을 플레이어가 확인할 수 있게 한다.

## D11. 기존 시스템 보존
- **Chosen**: 오수의 상단 HUD 안전 영역·판정 반경·5×5 진형·서버 패턴 매니페스트 동기화 구조는 유지한다.
- **Rationale**: 이번 변경은 루트·간격·템포·점수 보정에 집중하고, 이미 조정된 UI와 특수 진형의 회귀를 방지한다.
