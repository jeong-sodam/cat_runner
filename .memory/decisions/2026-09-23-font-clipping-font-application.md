# 글씨 잘림 현상 및 폰트 적용 결정

- 날짜: 2026-09-23
- 기능명: `font-clipping-font-application`
- 상태: 결정 완료

## 목표

로그인, 게임 HUD, 결과 화면, 개인기록표, 순위표 등 전체 UI와 캔버스 텍스트에서 폰트를 일관되게 적용하고, 제목·본문·카드가 좁은 화면에서도 잘리지 않도록 반응형 표시를 개선한다.

## 확정 결정

1. **폰트**
   - Pretendard Variable `woff2` 한 개를 프로젝트에 포함해 로컬 적용한다.
   - 폰트 로드 실패 시 `Noto Sans KR` → `맑은 고딕` → 시스템 폰트 순으로 대체한다.
   - 폰트 로딩 완료 후 주요 화면을 표시해 초기 레이아웃 흔들림을 방지한다.

2. **적용 범위**
   - 로그인 화면, 게임 HUD, 결과 화면, 개인기록표, 순위표 등 전체 HTML UI와 캔버스 텍스트에 적용한다.

3. **제목 표시**
   - 로그인 제목, 결과 제목, 개인기록표 제목 등 중요 제목은 한 줄을 우선한다.
   - 일반 화면에서는 28px, 좁은 화면에서는 20px까지 자동 축소한다.
   - 최소 크기에서도 넘치면 카드 폭을 넓히고 좌우 여백을 줄여 한 줄을 유지한다.

4. **본문 및 안내 문구**
   - 제목이 아닌 긴 문장은 영역 안에서 최대 2줄까지 자연스럽게 줄바꿈한다.

5. **캔버스 텍스트**
   - HUD와 아이템 안내 텍스트는 각 영역 안에서 글자 크기를 자동 축소한다.
   - 일반 UI 텍스트는 최소 12px, 캔버스 HUD 텍스트는 최소 10px까지 허용한다.
   - 게임 화면 전체를 축소하지 않고 텍스트만 보정한다.

6. **반응형 카드 레이아웃**
   - 최소 320px 화면 폭부터 데스크톱까지 지원한다.
   - 좁은 화면에서는 카드 폭과 내부 여백을 함께 줄여 가로 스크롤과 좌우 잘림을 방지한다.

## 구현 시 확인할 화면

- 로그인 화면의 제목 및 설명 문구
- 게임 HUD와 아이템/타겟 안내 문구
- 달리기 완료 결과 모달
- 개인기록표 및 순위표 제목, 표 설명, 최근 기록
- 일반 데스크톱과 320px 이상 좁은 화면
