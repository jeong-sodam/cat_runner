# Decisions: 공중 점프·숙이기, 피격범위 및 UI 축소

- Date: 2026-09-26
- Status: Confirmed
- Feature: `air-jump-slide-hitbox-ui-fit`

## D01. 공중 S 입력 동작

- **Chosen**: 점프 중 S를 처음 누른 순간 수직 속도를 즉시 `+900`으로 바꿔 빠르게 하강한다.
- **Rationale**: 점프 궤적을 즉시 종료하고 숙이기 장애물에 대응할 수 있게 한다. 현재 게임 설정의 점프 속도 크기 `900`을 하강 속도에도 사용한다.

## D02. 공중 S 해제와 숙이기 상태

- **Chosen**: S를 놓아도 하강은 계속한다. 착지했을 때 S를 누르고 있을 경우에만 숙인 자세와 slide 높이를 적용한다.
- **Rationale**: 하강 동작과 지상 숙이기 동작을 분리해 입력 결과를 예측 가능하게 한다.

## D03. 공중 S 발동 횟수

- **Chosen**: 같은 공중 체류 중 S 최초 입력에 한 번만 빠른 하강을 발동한다.
- **Rationale**: 키를 계속 누르거나 반복 keydown이 발생해도 속도가 누적·재적용되지 않도록 한다.

## D04. 2단 점프 복구

- **Chosen**: 2단 점프를 유지한다. 공중에서 두 번째 W를 누르면 현재 X/Y 위치를 유지한 채 수직 속도만 첫 점프와 동일한 `jumpVelocity × cat.jumpMultiplier`로 재설정한다.
- **Rationale**: 현재 구현의 지면 Y 재설정 때문에 공중 점프가 자연스럽게 이어지지 않는 문제를 제거하고, 고양이별 점프 능력치를 유지한다.

## D05. 2단 점프와 빠른 하강의 조합

- **Chosen**: S로 빠른 하강을 시작한 뒤에도 아직 사용하지 않은 2단 점프를 W로 사용할 수 있다.
- **Rationale**: S는 점프 횟수를 소모하지 않는 하강 전환이며, 플레이어에게 회복 가능한 조작 선택지를 남긴다.

## D06. 점프 횟수 제한

- **Chosen**: 한 번 공중에 있는 동안 추가 점프는 1회만 허용하고, 착지하면 점프 횟수를 초기화한다.
- **Rationale**: 일반적인 2단 점프 규칙을 유지하면서 무한 공중 점프를 방지한다.

## D07. 점프·숙이기 연속 패턴 보정 범위

- **Chosen**: `jump-slide`가 포함된 모든 연속 패턴을 보정한다.
- **Rationale**: 특정 패턴 하나가 아니라 동일한 입력 순서를 가진 패턴 전체에서 조작 타이밍을 일관되게 한다.

## D08. 패턴 장애물 위치

- **Chosen**: 점프 뒤 숙이기 장애물을 30 logical px 뒤로 이동하고, 그 뒤의 장애물도 함께 30px 이동한다.
- **Rationale**: 점프 후 S 입력과 빠른 하강 시간을 확보하면서 기존 장애물 간 간격과 패턴 리듬을 유지한다.

## D09. 피격범위

- **Chosen**: 플레이어 장애물 충돌용 박스를 가로 양쪽 10px, 세로 위·아래 4px씩 안쪽으로 줄인다. 쥐 인형·풀 획득 범위는 기존 범위를 유지한다.
- **Rationale**: 보이는 스프라이트 가장자리에 살짝 닿은 억울한 장애물 피격을 줄이되, 아이템 수집감은 바꾸지 않는다.

## D10. UI 스크롤 제거 범위

- **Chosen**: 로그인·닉네임·캐릭터 선택·결과·개인기록표·순위표·일시정지 등 모든 UI 화면에서 스크롤 없이 표시한다.
- **Rationale**: 특정 화면만 예외로 두지 않고 앱 전반의 사용 경험을 일관되게 한다.

## D11. UI 화면 쉘 높이

- **Chosen**: 실제 게임 화면은 기존 16:9를 유지하고, UI 화면은 브라우저 높이에서 바깥 여백을 뺀 `100dvh` 기준으로 세로 확장한다. 캔버스는 내부에서 16:9 레터박스로 유지한다.
- **Rationale**: 작은 화면에서도 UI 콘텐츠를 담을 공간을 확보하면서 실제 게임 플레이 배치와 감각은 보존한다.

## D12. UI 축소 기준

- **Chosen**: 제목 최소 18px, 본문 최소 11px, 표 최소 10px, 카드 여백 최소 10px까지 축소한다.
- **Rationale**: 320px 폭에서도 전체 UI를 담되 읽을 수 있는 하한을 유지한다.

## D13. 표 레이아웃

- **Chosen**: 모든 열과 정보를 유지하고, 내용 기반 자동 열 배분과 긴 셀 줄바꿈으로 가로 스크롤을 제거한다.
- **Rationale**: 개인기록·순위 정보 손실 없이 좁은 화면에 맞춘다.

## D14. 캐릭터 선택 레이아웃

- **Chosen**: 320px에서도 1열 카드를 유지하고 카드 높이를 극단적으로 줄인다. 이미지·이름·장단점·5개 능력치를 모두 표시하며 이미지는 48px 높이로 축소한다.
- **Rationale**: 기존 정보 구조를 유지하면서 작은 화면에서도 스크롤 없이 순차적으로 선택할 수 있게 한다.
