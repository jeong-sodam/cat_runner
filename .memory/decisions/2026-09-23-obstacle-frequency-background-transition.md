# Decisions: Obstacle Frequency and Background Transition

- Date: 2026-09-23
- Status: Confirmed

## D01. LOCAL 표기 제거 범위

- **Chosen**: 요청한 두 위치에서만 `LOCAL`을 제거한다.
- **Details**: 개인기록표 설명의 `LOCAL 플레이 개인 최고 기록 5개`에서 `LOCAL`을 제거하고, HUD의 정확도·타겟 아래 `LOCAL` 텍스트도 제거한다. 결과 화면 배지와 저장 경고의 `LOCAL` 표기는 유지한다.
- **Rationale**: 로컬 플레이 상태를 나타내는 결과 화면 정보는 유지하면서, 중복으로 보이는 설명·HUD 표기만 정리한다.

## D02. 장애물 증가 방식

- **Chosen**: 기존 패턴 구조는 유지하고 장애물 패턴 등장 빈도를 25% 높인다.
- **Scope**: 낮 실내·바깥·밤 실내 모든 구간에 적용한다.
- **Rationale**: 패턴을 새로 설계하기보다 현재 회피 동작과 시각 자산을 보존하면서 장애물 밀도를 높인다.

## D03. 장애물 간격 안전성

- **Chosen**: 패턴 간 간격을 줄이되, 현재 점프·슬라이드 안전 최소값과 안전 여유 아래로는 줄이지 않는다.
- **Rationale**: 장애물 수는 늘리면서도 회피 불가능한 조합과 부당한 피격을 방지한다.

## D04. 배경·난이도 전환 시점

- **Chosen**: 바깥 구간은 700점, 밤 실내 구간은 1800점에서 전환한다.
- **Rationale**: 초반부터 다음 배경과 장애물 패턴을 더 빠르게 경험하도록 전환 시점을 앞당긴다.

## D05. 배경과 난이도 전환 동기화

- **Chosen**: 700점·1800점에서 배경과 난이도를 동시에 즉시 전환한다.
- **Rationale**: 현재 zone 기반 구조를 유지하면서 플레이어가 구간 변화를 명확히 인지할 수 있다.

## D06. 기존 구간 난이도 배율

- **Chosen**: 구간별 기존 난이도 배율은 유지한다.
- **Rationale**: 전환 시점 단축과 장애물 빈도 증가가 이미 난이도를 높이므로, 배율까지 올리면 과도한 난이도 상승이 될 수 있다.

## D07. HUD 레이아웃

- **Chosen**: HUD에서 `LOCAL` 제거 후 오른쪽 정보 패널 높이를 줄여 빈 공간을 없앤다.
- **Rationale**: 정확도와 활성 타겟 정보만 남기고 패널을 해당 정보에 맞게 정리한다.
