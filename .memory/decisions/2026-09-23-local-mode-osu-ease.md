# Decisions: Local Mode and osu Ease

- Date: 2026-09-23
- Status: Confirmed

## D01. 신규 플레이 모드
- **Chosen**: 로그인 여부와 서버 상태에 관계없이 모든 신규 플레이를 LOCAL 모드로 시작한다.
- **Rationale**: 현재 배포 환경에서는 서버 저장 실패가 발생해 개인기록표에 도달하지 못하므로, 로컬 기록 흐름을 항상 사용한다.

## D02. 서버 기능 보존 범위
- **Chosen**: 서버 API와 서버 순위표 코드는 유지하지만, 현재 신규 플레이에서는 `startRun`, 서버 재개 확인, 서버 게임오버 저장을 호출하지 않는다. 서버용 `순위표` 버튼은 준비 중 안내만 표시한다.
- **Rationale**: 추후 로그인·배포를 대비해 코드를 보존하되, 현재 플레이 결과가 서버 실패 화면으로 빠지는 경로를 제거한다.

## D03. 서버 재개 처리
- **Chosen**: 기존 서버 재개 기록 확인과 재개 기능도 건너뛰고 항상 새 LOCAL 플레이로 시작한다.
- **Rationale**: 현재 모든 플레이를 LOCAL로 고정한다는 결정과 일관되며 서버 재개 팝업이 로컬 기록 흐름을 방해하지 않는다.

## D04. 로컬 저장 실패 처리
- **Chosen**: `localStorage` 쓰기가 차단되어도 현재 세션의 메모리 저장소에 기록을 유지하고 `개인기록표`는 열 수 있게 하며, 브라우저 저장 실패 경고를 표시한다.
- **Rationale**: 저장소 권한 문제 때문에 결과 확인과 개인 순위 확인까지 막히지 않게 한다. 브라우저를 닫은 뒤에도 유지되는 영속 저장은 가능한 경우에만 제공한다.

## D05. osu 타겟 크기와 판정 범위
- **Chosen**: 현재 타겟 반지름 기준으로 시각적 원과 판정 범위를 함께 25% 확대한다.
- **Rationale**: 사용자가 화면에서 타겟을 더 쉽게 보고 클릭할 수 있도록 시각 피드백과 실제 인정 범위를 일치시킨다.

## D06. osu 등장 간격
- **Chosen**: 모든 구역의 타겟 등장 간격을 1,000ms로 통일한다.
- **Rationale**: 구역별 750/500/375ms 등장 속도가 너무 빠르므로 난이도 급상승을 제거한다.

## D07. osu 타겟 간 거리
- **Chosen**: 연속 타겟의 최소 거리를 160px에서 100px로 줄인다.
- **Rationale**: 다음 타겟으로 이동해야 하는 마우스 이동량을 줄인다.

## D08. osu 타겟 유지 시간
- **Chosen**: 타겟 유지 시간을 750ms에서 1,000ms로 늘린다.
- **Rationale**: 타겟을 확인하고 이동·클릭할 수 있는 시간을 추가로 제공한다.

## D09. 동시 등장 개수
- **Chosen**: 구역별 동시 등장 개수 `home_day 1개 · outside 2개 · home_night 3개`는 유지한다.
- **Rationale**: 완화 대상은 속도·이동·판정이며, 구역별 난이도 구조는 보존한다.
