# Decisions: 고양이 러너 게임 (cat-runner)

- Date: 2026-09-21
- Status: Confirmed

## D01. 게임 장르와 진행
- **Chosen**: 자동 횡스크롤 무한 러너
- **Rationale**: 고양이가 자동으로 달리고 플레이어는 점프와 회피에 집중한다. 체력이 0이 될 때까지 진행하며 최고 점수를 경쟁한다.

## D02. 조작
- **Chosen**: `W` 점프, `S` 슬라이딩, `P` 일시정지
- **Details**: `W`는 2단 점프를 지원한다. `S`는 누르는 동안 슬라이딩한다. 일시정지는 `P` 키와 화면 버튼으로 제공한다.

## D03. 기술 기반
- **Chosen**: HTML5 Canvas + 순수 JavaScript, Node.js + Express 단일 서버
- **Rationale**: Express가 게임 정적 파일과 API를 함께 제공하며, 프론트엔드와 백엔드 모두 JavaScript로 관리한다.

## D04. 화면과 시각 스타일
- **Chosen**: 가로형 16:9 화면, 밝고 귀여운 2D 카툰 스타일
- **Details**: 초기 캐릭터·아이템은 코드로 그리되, 렌더링 구조를 분리해 추후 PNG 스프라이트로 교체할 수 있게 한다.

## D05. 캐릭터 선택
- **Chosen**: 검정, 하양, 삼색, 치즈, 고등어, 카오스 6종을 매 게임 시작 전에 선택
- **Rationale**: 선택한 캐릭터를 계정에 영구 고정하지 않고 매 판 전략에 따라 바꿀 수 있게 한다.

## D06. 캐릭터 능력치
- **Chosen**: 점프력·이동 속도·슬라이딩 속도·아이템 지속 시간·체력의 5개 능력치 사용
- **Balance**: 각 고양이는 장점 1개와 약점 1개를 가지며 기본값 대비 ±10%를 적용한다.
- **Mapping**:
  - 검정: 이동 속도 `+` / 체력 `-`
  - 하양: 점프력 `+` / 슬라이딩 속도 `-`
  - 삼색: 체력 `+` / 이동 속도 `-`
  - 치즈: 아이템 지속 시간 `+` / 점프력 `-`
  - 고등어: 슬라이딩 속도 `+` / 아이템 지속 시간 `-`
  - 카오스: 이동 속도 `+` / 점프력 `-`
- **Health model**: 내부 체력은 30 단위로 계산하고 UI에는 3칸으로 표시한다.

## D07. 수집물과 점수
- **Chosen**: 쥐 인형은 점수 아이템, 강아지풀은 랜덤 보너스 아이템
- **Score**: 쥐 인형 1개당 10점, 이동 거리 1m당 1점
- **Grass effects**: 자석, 무적, 점수 2배, 꽝이 각각 25% 확률로 발동한다.
- **Duration**: 긍정적인 보너스 효과는 기본 5초이며 아이템 지속 시간 능력치의 영향을 받는다. 효과 중 강아지풀을 다시 먹으면 기존 효과를 새 랜덤 효과로 즉시 교체한다.
- **Failure effect**: 꽝은 5초 동안 이동 속도를 감소시키며, 아이템 지속 시간 능력치의 영향을 받지 않는다.
- **Display**: 보너스 효과는 캐릭터 주변 색상과 이펙트로 표시한다.

## D08. 충돌과 난이도
- **Chosen**: 체력 3칸, 충돌할 때마다 체력 감소, 0이면 게임 오버
- **Difficulty**: 시간이 지날수록 속도와 장애물 난도가 점진적으로 상승한다.
- **Generation**: 미리 검증한 장애물·아이템 패턴을 섞어 생성해 불가능한 배치를 방지한다.

## D09. 배경 진행
- **Chosen**: 구역을 한 번만 진행
- **Sequence**: 집 안에서 시작 → 집 밖(골목·공원) → 마지막 집 안 구간
- **Transitions**: 1,000점에서 집 밖으로 전환하고, 2,500점에서 마지막 집 안으로 전환한다. 마지막 구간에서는 최고 난도로 계속 진행한다.

## D10. 오디오
- **Chosen**: 배경음악과 효과음 모두 제공
- **Implementation**: 초기에는 Web Audio API로 생성하고, 사운드 모듈을 분리해 추후 오디오 파일로 교체할 수 있게 한다.
- **Controls**: 음소거 버튼과 배경음악·효과음 개별 음량 조절 슬라이더를 제공한다.

## D11. 결과 화면
- **Chosen**: 게임 오버 후 점수·거리·순위를 보여주고 `다시 시작` 버튼을 제공
- **Details**: 최고 점수 갱신 여부를 결과 화면에 표시한다.

## D12. 인증과 사용자
- **Chosen**: 모든 조직의 Microsoft Entra 계정이 로그인 가능한 멀티테넌트 인증
- **Flow**: 게임 시작 전에 반드시 로그인한다. 서버 측 세션 로그인과 SQLite 세션 저장을 사용한다.
- **Nickname**: 첫 로그인 때 직접 입력하고 이후 변경할 수 있다. 길이·문자 제한은 거의 두지 않으며 중복 닉네임을 허용한다. 리더보드에서는 이메일로 사용자를 구분한다.
- **Privacy decision**: 리더보드에 닉네임과 전체 이메일 주소를 표시한다.
- **Local config**: `.env` 설정이 없으면 로그인 화면에 설정 안내를 표시하고 게임을 시작하지 않는다.

## D13. 리더보드
- **Chosen**: 전체 최고 점수 기준 상위 10명만 표시
- **Persistence**: 사용자별 최고 점수 1개만 저장한다.
- **Tie-breaker**: 점수가 같으면 더 먼 거리를 달린 기록이 높은 순위가 된다.
- **Target storage**: 현재 로컬 개발은 SQLite로 구현하고, 추후 Azure Cosmos DB로 교체 가능한 저장소 계층을 둔다.

## D14. 점수 검증
- **Chosen**: 서버가 수집·충돌·거리 이벤트와 시간 정보를 검증한다.
- **Rationale**: 클라이언트 최종 점수만 신뢰하지 않고, 플레이 이벤트를 기반으로 서버가 최종 점수를 계산한다.

## D15. 연결 끊김과 이어하기
- **Chosen**: 연결이 끊기면 게임 상태와 검증 이벤트를 임시 저장하고 게임을 멈춘다. 연결 복구 후 저장된 지점부터 재개한다.
- **Browser restart**: 브라우저 종료·새로고침 후에도 마지막 상태를 복구할 수 있다.
- **Resume UX**: 재접속 시 “이어서 플레이하시겠습니까?”를 묻는다.
- **Expiry**: 저장된 진행 상태는 24시간 후 만료된다.

## D16. 개발 범위
- **Chosen**: 우선 로컬 실행·테스트를 완성한다.
- **Current stack**: Node.js, Express, HTML5 Canvas, 순수 JavaScript, SQLite, 서버 측 Entra 세션 인증
- **Future migration**: 로컬 SQLite를 Azure Cosmos DB로 교체하고, 실제 운영 배포를 추가한다.
